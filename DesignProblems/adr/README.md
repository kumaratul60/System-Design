# Architecture Decision Records (ADRs)

This directory contains the formal Architecture Decision Records for the System Design problems in this repository.

## Naming Convention
All ADR documents must follow this naming convention:
```text
{00x}-{date}-{slug}.md
```
* `{00x}`: 3-digit zero-padded incremental sequence number (e.g. `001`, `002`, `003`).
* `{date}`: ISO-8601 date format `YYYY-MM-DD` when the ADR was authored (e.g. `2026-11-22`).
* `{slug}`: Kebab-case descriptive slug of the problem or architecture domain (e.g. `clickstream-aggregator`).
