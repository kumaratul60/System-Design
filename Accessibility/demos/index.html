🎙️ How to Turn On & Operate Screen Readers (macOS & Windows)

Follow these steps to enable native screen readers on your machine and test the interactive demos above:

🍎 macOS (Apple VoiceOver)

  • Toggle On/Off: Cmd + F5 (or triple-click Touch ID)
  • VoiceOver Key (VO): Ctrl + Option
  • Next / Prev Item: VO + → / VO + ←
  • Activate / Click: VO + Space
  • Open Rotor: VO + U (Headings, Landmarks, Links)
  • Safari Prerequisite: Safari → Settings → Advanced → Check "Press Tab to highlight each item"

🪟 Windows (NVDA & Narrator)

  • Start NVDA: Ctrl + Alt + N (Stop: NVDA + Q)
  • Start Narrator: Win + Ctrl + Enter
  • NVDA Modifier: Insert or Caps Lock
  • Next Heading: Press H (Forms: F, Buttons: B)
  • Elements List: NVDA + F7
  • Toggle Forced Colors: Left Alt + Left Shift + PrintScreen
