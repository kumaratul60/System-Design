08: Accessible Accordion (Zero Ghost Focus)

Demonstrates the WAI-ARIA Accordion Pattern. Uses aria-expanded and aria-controls. When collapsed, CSS visibility: hidden ensures that internal links/buttons are completely removed from the keyboard tab sequence.

Web accessibility means designing digital tools so that everyone, including over 1.3 billion people with disabilities, can perceive, understand, navigate, and interact with the web.

The 4 foundational principles of the Web Content Accessibility Guidelines (WCAG): Perceivable, Operable, Understandable, and Robust.

When aria-expanded="true" is set on the header button, screen readers announce "Expanded", telling the user that the content panel is visible and ready to explore.
Active Focus: <body> | Accordion Status: All closed (internal buttons unreachable via Tab)
